# Code général des impôts

Loi n° 2012-31 du 31 décembre 2012 portant Code général des impôts. Texte consolidé, daté du jour de sa dernière modification mentionnée (Loi n° 2025-02 du 6 janvier 2025) ; l'historique de ce code commence à cette consolidation (le texte tel qu'adopté et les versions intermédiaires ne sont pas disponibles sous forme de texte). Source (consolidated copy (dgid.sn)) : <https://www.dgid.sn/loi-reglement> ; fichier : <https://www.dgid.sn/storage/docs/CGI-2025.pdf>. Les numéros d'articles absents de la copie source n'y figurent pas.

Édition annotée de la DGID (droit positif seulement ; les dispositions abrogées en sont absentes) : les circulaires et notes que la DGID a imprimées à l'intérieur des articles figurent dans le texte des articles.
