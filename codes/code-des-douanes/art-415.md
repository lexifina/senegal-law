# Article 415
Les personnes à l’encontre desquelles un procès verbal a été dressé sur la base de l’article 312 du présent code peuvent exercer le recours visé à l’article précédent. Le cas échéant, l’enregistrement du procès- verbal, ainsi que tous les actes de poursuite sont suspendus jusqu’ à la réponse définitive du Directeur général des douanes.
