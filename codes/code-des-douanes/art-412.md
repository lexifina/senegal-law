# Article 412
1. Tout fait tombant sous le coup de dispositions répressives distinctes édictées par le présent code doit être envisagé sous la plus haute qualification pénale dont il est susceptible.
2. En cas de pluralité de contraventions ou de délits douaniers, les condamnations pécuniaires sont prononcées pour chacune des infractions dûment établies.
