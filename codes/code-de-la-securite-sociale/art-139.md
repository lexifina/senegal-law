# Article 139
Les cotisations dues par les employeurs doivent faire l'objet d'un versement :
Ω dans les quinze premiers jours de chaque mois si l'employeur occupe vingt salariés ou plus ;
Ω dans les quinze premiers jours de chaque trimestre si l'employeur occupe moins de vingt salariés.
L'autorité compétente pourra déterminer les conditions dans lesquelles et les modalités selon lesquelles une ou des unions de recouvrement pourront se substituer aux institutions de sécurité sociale tant pour le recouvrement des cotisations dues par les employeurs et les travailleurs, ainsi que pour les assurés volontaires, que pour le contrôle et le contentieux du recouvrement.
