# Article R.59
Le pâturage et le passage des animaux domestiques dans le domaine forestier national sont autorisés. Ils sont, cependant, interdis dans les parcs nationaux, dans les périmètres de reboisement ou de restauration, dans les parcelles de forêts en voie de régénération naturelle ou dans les zones repeuplées artificiellement, tant que la présence dans animaux risque d'endommager les plantations.
Le parcours du bétail peut également être réglementé en cas de nécessité ou d'aménagement particulier.
