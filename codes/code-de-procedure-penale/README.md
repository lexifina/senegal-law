# Code de procédure pénale

Loi n° 65-61 du 21 juillet 1965 portant Code de procédure pénale. Texte consolidé, daté du jour de sa dernière modification mentionnée (Loi n° 99-06 du 29 janvier 1999) ; l'historique de ce code commence à cette consolidation (le texte tel qu'adopté et les versions intermédiaires ne sont pas disponibles sous forme de texte). Source (consolidated copy (vie-publique.sn)) : <https://www.vie-publique.sn/documents/7945/code-de-procedure-penale-senegal-7945> ; fichier : <https://www.vie-publique.sn/docs/86d88dc3-100a-46b0-949a-d4d9cb234c53/code-de-procedure-penale-senegal-7945.pdf>. Les numéros d'articles absents de la copie source n'y figurent pas.

Les modifications ultérieures à la Loi n° 99-06 (par exemple la Loi n° 2016-30) ne figurent pas dans cette copie.
