# Article 6
Enfant adoptif L’adoption plénière confère à l’enfant le nom de l’adoptant et, en cas d’adoption par deux époux, le nom du mari. Toutefois les enfants du mari adoptés par l’épouse de celui-ci conservent le nom de leur père.
L’enfant faisant l’objet d’une adoption limitée porte le nom de l’adoptant qu’il ajoute à son nom de famille; cependant le juge peut, dans l’intérêt de l’enfant, décider qu’il portera seulement le nom de l’adoptant.
