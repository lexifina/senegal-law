# Article 48
Le droit de préemption destiné notamment à permettre la mise en oeuvre d'une politique d'urbanisme et d'habitat, peut être exercé pour les opérations suivantes :
réalisation de logements sociaux ou d'équipements collectifs ;
restauration de bâtiments ou rénovation urbaine ;
création d'espaces verts ;
constitution de réserves foncières.
