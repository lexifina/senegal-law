# Article 52
Des décrets pris sur rapport des Ministres chargées de l'Hydraulique et de l'Assainissement, classent les cours d'eau, canaux, lacs, étangs ou eaux souterraines en fonction des usages auxquels leurs eaux sont destinées :
Consommation humaine ;
Production d'aliments pour l'alimentation humaine ;
Elevage, agriculture, pisciculture, sylviculture ;
Utilisation minière hydroélectrique ;
Navigation ;
Activités récréatives.
