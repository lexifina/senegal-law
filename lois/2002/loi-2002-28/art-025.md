# Article 25
Les Etats membres sont tenus de contrôler le respect des conditions requises par cette Réglementation commune, notamment :
i la qualité des formulations mises sur le marché ;
ii les domaines d'utilisation autorisés et les restrictions données sur les APV et les homologations ;
iii les normes et les indications figurant sur les étiquettes ;
iv l'utilisation des pesticides commercialisés selon les indications mentionnées sur les étiquettes ;
v. les effets des pesticides sur l'environnement.
