# Article 2
L'équipe pays est chargée de :
- orienter la planification et l'exécution du PPAB ;
- superviser les activités menées dans le cadre de l'exécution du programme ;
- examiner et approuver le budget ;
- préparer toutes les concertations avec les différents partenaires stratégiques ;
- étudier toutes les autres questions liées à la réalisation du Programme ;
- approuver les opérations annuelles d'exécution du Programme.
