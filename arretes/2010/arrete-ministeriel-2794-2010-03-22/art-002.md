# Article 2
Les actes médicaux dans les structures publiques de santé sont accessibles gratuitement pour les bénéficiaires du Plan SESAME à l'exclusion des prestations suivantes :
soins de dialyses rénales ;
prothèse (dentaires, de hanches, etc...) ;
implants sauf les implants oculaires ;
pace maker ;
évacuations sanitaires pour l'étranger ;
médicaments de spécialités des (officines privées) ;
IRM ;
scanners sauf urgence ;
hospitalisations en 1ere et 2eme catégorie ;
soins de beauté ;
chirurgie esthétique ;
bilan systématique.
