# Article 4
Les effets d'habillement agréés pour le personnel sont les suivants :
- un pantalon de couleur noire ;
- une chemise de couleur noire avec logo sur la poche gauche, sur le dos. Le sigle « AS » est visible sur la manche droite ;
- une casquette de couleur noire avec le logo de l'agence au front ;
- une paire de chaussures Rangers de couleur noire.
