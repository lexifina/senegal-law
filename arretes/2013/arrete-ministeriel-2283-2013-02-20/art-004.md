# Article 4
Les effets d'habillement agréés pour le personnel sont les suivants :
- un pantalon de couleur beige avec bandes latérales de couleur rouge ;
- une chemise de couleur beige, munie d'épaulettes de couleur rouge avec le logo de l'entreprise sur le dos ;
- une cravate de couleur rouge ;
- une ceinture de couleur verte, jaune et rouge ;
- un Képi de couleur beige avec logo sur le front ;
- une paire de chaussures de couleur noire.
