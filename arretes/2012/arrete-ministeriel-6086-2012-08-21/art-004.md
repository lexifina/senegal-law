# Article 4
Les effets d'habillement agréés pour le personnel sont les suivants :
- un pantalon de couleur beige, avec bande latérale noire,
- une chemise de couleur beige munie d'épaulette noire, avec le logo de l'entreprise sur le dos
- une cravate de couleur noire portant le logo de
l'entreprise,
- une casquette de couleur noire avec logo de l'entreprise,
- une paire de chaussures basses de couleur noire.
