# Article 4
Les effets d'habillement agréés pour le personnel sont les suivants :
- un pantalon de couleur noire avec deux poches latérales,
- une chemise de couleur jaune, munie d'épaulettes et de deux poches sur la poitrine, avec sur le dos le logo de l'entreprise
- un ceinturon de couleur noire,
- une casquette de couleur noire avec le logo sur le front,
- une paire de chaussures basses de couleur noire.
