# Article 3
De la Composition
Chaque Comité de Gestion est composé comme suit :
Président :
- représentant du Ministre des Sports ;
Secrétaire exécutif :
- Directeur du Stade ;
Trésorier :
- Gestionnaire du Stade ;
Six membres :
- le représentant du DAGE ;
- deux représentants des utilisateurs qui ont leur siège dans le site ;
- le représentant du Personnel du Stade ;
- le représentant des Partenaires - Bénéficiaires commerciaux.
