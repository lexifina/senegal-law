# Article premier
Le nombre de bulletins de vote pris en charge par l'Etat pour un parti politique ou une coalition de partis politiques qui se présente dans toutes les collectivités locales, est fixé comme suit :
3.750.000 bulletins de vote format 210 mm X 297 mm pour les élections régionales ;
1.800.000 bulletins de vote format 210 mm X 297 mm pour les élections municipales ;
1.950.000 bulletins de vote format 110 mm X 180 mm pour les élections rurales.
