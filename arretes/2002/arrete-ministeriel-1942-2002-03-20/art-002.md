# Article 2
Le nombre de documents de propagande pris en charge par l'Etat pour un parti politique ou une coalition de partis politiques qui se présente dans toutes les collectivités locales, est fixé comme suit :
10.780 affiches de format 56 X 90 cm, destinées à faire connaître le programme des listes de candidats pour les élections régionales ;
10.780 affiches de format 28 X 45 cm destinées à annoncer des réunions électorales de propagande pour les élections régionales ;
11.610 affiches de format 56 X 90 cm, destinées à faire connaître le programme des listes de candidats pour les élections municipales et rurales ;
10.610 affiches de format 28 X 45 cm destinées à annoncer des réunions électorales de propagande pour les élections municipales et rurales.
Le nombre de documents de propagande à imprimer pour chaque parti politique ou coalition de partis politiques est fonction des collectivités locales où il se
présente.
