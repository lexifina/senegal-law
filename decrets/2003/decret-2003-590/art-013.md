# Article 13
Les notes des Unités de Valeur sont calculées
comme suit :
UV sans TP : (max(Contrôle continu, Examen) + 2 Examen)/3
UV avec TP : (Contrôle continu + TP + 2 Examen)/4
UV sans TP : (max(Contrôle continu, Examen) + 2 Examen)/3
UV avec TP : (Contrôle continu + TP + 3 Examen)/5
Dans le cas des UV où des projets ont été proposés, ces derniers sont considérés comme des TP.
