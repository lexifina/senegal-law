# Article 7
le montant du crédit susceptible d'être consenti à l'occasion d'une vente à tempérament ne peut excéder une fraction du prix de l'objet fixée à :
85 % pour les véhicules de tourisme neufs à usage personnel ou de taxis d'une puissance inférieure à 11 CV ;
80 % pour les véhicules de tourisme neufs à usage personnel ou de taxis d'une puissance égale ou supérieure à 11 CV ;
80 % pour les cars neufs de transport de personnes ;
85 % pour les véhicules utilitaires neufs, genre pick-up, camionnette ou fourgonnette ;
85 % pour les camions et tracteurs d'un poids total en charge inférieur ou égal à dix (10) tonnes ;
90 % pour les camions et tracteurs d'un poids total en charge supérieur à dix (10 tonnes) ;
75 % pour les véhicules de tourisme d'occasion de moins de (7) ans ;
60 % pour les véhicules de tourisme de plus de sept (7) ans ;
85 % pour les cyclomoteurs fabriqués ou montés au Sénégal ;
80 % pour les cyclomoteurs importés ;
90 % pour les appareils électroménagers et domestiques, les récepteurs de radiodiffusion et télévision ainsi que les électrophones ;
90 % pour les meubles meublants fabriqués au Sénégal ;
85 % pour les meubles meublants importés ;
90 % pour les matériaux de construction.
