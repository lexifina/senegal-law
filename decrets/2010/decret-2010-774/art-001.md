3.Centre de santé de référence Youssou Mbargane de Rufisque ;
4.Centre de santé de référence Ndamatou de Touba ;
5.Centre de santé de référence de Richard Toll ;
6.Centre de santé de référence de Sédhiou ;
7.Centre de santé de référence de Kaffrine ;
8.Centre de santé de référence de Mbour ;
9.Centre de santé de référence de Tivaouane ;
10.Centre de santé de référence de Linguère.
