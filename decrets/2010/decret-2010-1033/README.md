# DECRET n° 2010-1033 en date du 4 août 2010 déclarant d'utilité publique le projet d'exploitation d'un verger, sur un terrain du domaine national situé à Ndiar, Communauté rurale de Diender, dans le Département de Thiès, d'une superficie de 27.510 mètres carrés. Prescrivant l'immatriculation au nom de l'Etat, dudit terrain.
