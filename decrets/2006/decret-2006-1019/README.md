# DECRET n° 2006-1019 en date du 3 octobre 2006 déclarant d'utilité publique le projet de réalisation d'une exploitation agricole sur un terrain du domaine national situé à Ngaparou, dans le département de Mbour, d'une superficie de 8 hectares 77 ares 92 centiares et prescrivant l'immatriculation au nom de l'Etat dudit terrain.
