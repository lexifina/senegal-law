# Article 2
Les villages qui composent la Communauté rurale de Khelcom sont :
1. Dianatoul Mahwa ;
2. Darou Tanzil ;
3. Touba Bélel ;
4. Darou Mouhty ;
5. Darou Rahmane ;
6. Ndindy ;
7. Ousnoul Mahab ;
8. Darou Khoudoss ;
9. Touba-Khelcom (chef-lieu) ;
10. Darou Salam ;
11. Darou Minam ;
12. Darou Marnane ;
13. Oumoul Khoura ;
14. Daroul Alimoul Khabir ;
15. Taïba.
