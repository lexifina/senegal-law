# Article premier
Le Certificat d'Aptitude à l'Enseignement dans le cycle secondaire (CAES) est délivré par arrêté du Ministre chargé de l'Enseignement supérieur, sur proposition d'un jury d'examen constitué à cet effet.
Le CAES peut être délivré pour toutes les options correspondant aux disciplines enseignées dans le cycle secondaire.
