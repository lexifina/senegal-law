# Article 43
Le système d'évaluation est basé sur les évaluations formatives, sommatives et de certification. Le passage en classe supérieure est décidé par le Conseil de Classe sur la base de la réussite à tous les modules de l'année d'études.
Le niveau acceptable de performance requis pour réussir un module est fixé à 60%. L'échelle de mesure utilisée à cet effet peut être graduée de 0 à 100 ou de 0 à 20.
