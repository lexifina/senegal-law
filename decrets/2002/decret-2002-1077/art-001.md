# Article premier
l'article 3 du décret 99-1211 du 20 décembre 1999 est complété par les dispositions suivantes :
Les jeux ordinaires cités ci-dessous pourront
également y être pratiqués :
· deux tables de Boule ;
· deux tables de Baccara chemin de fer ;
· deux tables de Baccara à deux tableaux ;
· deux tables de Ramy Poker ;
· deux tables de Bingo.
