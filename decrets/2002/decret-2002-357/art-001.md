# Article premier
L'article R14 est abrogé et
remplacé par les dispositions suivantes :
Dans le présent code, les compétences conférées aux gouverneurs, aux préfets et aux sous-préfets concernent :
Les régions pour les gouverneurs ;
Les communes et les communes d'arrondissement pour les Préfets ;
Les communautés rurales pour les Sous-Préfets.
