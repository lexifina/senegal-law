# Article 8
Le manjakú connaît la prénasalisation. Pour orthographier les prénasales, la lettre m est utilisée devant p et b, et la lettre n devant les autres consonnes.
Exemples :
mb => kabamb
« le battant »
mp => mpat
« la crème de lait »
nk => bëtënk
« l'entraide »
nj => bëleenj
« le pagne »
ng => uloong
« l'éléphant »
nt => pëlent
« la plainte »
nd => undink
« la hache »
nc => uncaam
« de l'argent »
nt => pëtant
« la queue ».
