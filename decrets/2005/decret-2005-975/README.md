# DECRET n° 2005-975 en date du 20 octobre 2005 déclarant d'utilité publique le projet d'exploitation d'une unité industrielle de décorticage de riz sur un terrain du domaine national, situé à Soutouré dans la Sous-Préfecture de Kounkané, Région de Kolda, d'une superficie de 7.445 mètres carrés, prescrivant l'immatriculation au nom de l'Etat dudit terrain.
