# Article 4
Toutes les consonnes occlusives du wolof peuvent être prénalisées. Pour les orthographier, la nasale m est utilisée devant les labiales b et p, et la nasale n devant toutes les autres consonnes :
Exemples :
mb
=>
mboot
« cafard »
mp
=>
nàmp
« téter »
nd
=>
ndox
« eau »
ng
=>
ngoon
« soir »
nj
=>
njaay
« vente » / nom de famille
nc
=>
denc
« garder »
nk
=>
tànk
« jambe, pied »
nq
=>
xonq
« rouge »
nt
=>
bunt
« porte ».
