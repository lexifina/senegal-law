# DECRET n° 2004-1642 en date du 30 décembre 2004 déclarant d'utilité publique le projet de réalisation d'une exploitation agricole sur un terrain du domaine national, situé à Ngaparou, dans le Département de Mbour, d'une superficie de 6.086 mètres carrés et prescrivant l'immatriculation au nom de l'Etat dudit terrain.
