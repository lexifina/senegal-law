# Article 3
L'établissement comprendra les supports de jeux suivants :
Boule six (6) tableaux ;
Jeu de 23 deux (2) tableaux ;
Baccara-chemin de fer quatre (4) tables ;
Baccara à deux tableau banque
limitée (1) table ;
Baccara à banque ouverte une (1) table ;
Roulette six (6) tables ;
Trente et quarante une (1) table.
