# Article R.18
La servitude d'égout de toits interdit à tout propriétaire de faire s'écouler directement sur les terrains voisins les eaux pluviales tombées sur le toit de ses constructions.
Les eaux pluviales tombant sur les toits doivent être dirigées soit sur le propre terrain du propriétaire des constructions soit sur la voie publique, dans les conditions prévues par le Code de l'Assainissement.
En tout état de cause, il est interdit de déverser des eaux pluviales dans les ouvrages d'assainissement autonome.
