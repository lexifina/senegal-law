# Article 3
Il est créé, dans l'Arrondissement de Sangalcam, Département de Rufisque, Région de Dakar, la communauté rurale de Bambylor.
La communauté rurale de Bambylor, ayant commne chef-lieu le village centre de Bambylor, est composée des villages ci-après :
1. Bambilor ;
2. Diacksao ;
3. Déni Biram Ndao Nord ;
4. Déni Biram Ndao Sud ;
5. Déni Guédji Sud ;
6. Kaniack ;
7. Keur Ndiaye Lô ;
8. Keur Daouda Sarr ;
9. Kounoune ;
10. Kounoune Ngalap ;
11. Mbeuth ;
12. Mbèye ;
13. Niakhirate Peulh ;
14. Ngendouf ;
15. Gorom 1 ;
16. Gorom II ;
17. Gorom III ;
18. Wayambame.
Les localités communément appelées cités El Hadji Doudou Basse, Mbaba Guissé et SAGEF Kounoune font partie intégrante de la communauté rurale de Bambylor.
