# DEcret n° 2011-319 en date du 7 mars 2011 portant déclarant d'utilité publique le projet de réalisation d'un établissement d'enseignement supérieur privé dénommé « Université Panafricaine pour les Sciences et la Technologie » sur un terrain du domaine national situé à la Somone, dans le département de Mbour, d'une superficie de 3.103 m2. prescrivant l'immatriculation, au nom de l'Etat dudit terrain.
