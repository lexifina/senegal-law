# Article 4
Il est créé, dans le Département de Rufisque, Région de Dakar, la Communauté rurale de Tivaouane Peulh-Niaga.
La Communauté rurale de Tivaoune Peulh-Niaga, ayant comme Chef-lieu le village centre de Tivaouane Peulh, est composée des villages ci-après :
1. Tivaouane Peulh ;
7. Keur Marème Mbengue ;
2. Bénoba ;
8. Niaga Wolof ;
3. Cité Darou Salam ;
9. Niaga Peulh ;
4. Cité SAFCO ;
10. Cité SOCABEG ;
5. Cité UCAD II ;
11. Cité NAMORA ;
6. Déni Guédji Nord ;
12. Cité Groupe NABY ;
13. Recasés de l'Autoroute.
