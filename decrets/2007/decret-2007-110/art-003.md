# Article 3
Pour les trajets supérieurs à 250 km en chargement complet, les suppléments prévus pour sujétions de déplacement sont les suivants :
- Trajets supérieurs à 250 km (Casamance
exclue) : supplément pour sujétions de déplacement :
- produits blancs 63,15 F/HL ;
- produits noirs 781,8 F/T ;
- Trajets Dakar – Casamance : supplément pour sujétion de déplacement et bacs :
- produits blancs 313,58 F/HL.km+40% ;
- produits noirs 3129,40 F/T.
