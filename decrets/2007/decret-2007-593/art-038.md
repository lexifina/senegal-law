# Article 38
La convention de financement sera exécutée par l'adjudicataire dans les trente jours ouvrables suivant la signature du contrat de licence.
La convention sera exécutée sur la base du pro forma inclus dans les soumissions de base et peut être amendée, le cas échéant, pourvu que de tels amendements n'entraînent la modification des exigences essentielles ni dans les conditions ni dans les résultats de l'évaluation.
