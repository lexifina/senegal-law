# Article 8
Outre les éléments de l'actif qui intègrent les créances, le déclarant doit mentionner le passif de son patrimoine incluant les dettes hypothécaires, les dettes personnelles, les dettes communes (sous le régime communautaire) et tout autre engagement qu'il juge nécessaire de signaler.
La mention NEANT doit être inscrite dans les rubriques non remplies.
