# Article 14
La rémunération mensuelle des secrétaires dactylographes est fixée comme suit :
Première classe :
1er échelon : titulaire du C.A.P de dactylographie : 25.400 F ;
2e échelon : 27.000 F ;
Deuxième classe :
1er échelon : 29.100 F ;
2e échelon : 31.500 F ;
Troisième classe :
1er échelon : 32.900 F ;
2e échelon : 35.100 F ;
3e échelon : 37.400 F ;
Classe Exceptionnelle : 41.000 F.
