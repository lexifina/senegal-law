# Article 18
La rémunération des secrétaires sténodactylographes ou sténotypistes est fixée comme suit :
A. Sténodactylographes :
Première classe :
1er échelon : titulaire du C.A.P : 29.300 F ;
2e échelon : 35.000 F ;
Deuxième classe :
1er échelon : 40.700 F ;
2e échelon : 43.900 F ;
Troisième classe :
1er échelon : 47.200 F ;
2e échelon : 49.500 F ;
Classe exceptionnelle : 57.500 F.
B. Sténotypistes :
Première classe :
1er échelon : 29.300 F ;
2e échelon : 35.000 F ;
Deuxième classe :
1er échelon : 40.700 F ;
2e échelon : 43.900 F ;
Troisième classe :
1er échelon : 47.200 F ;
2e échelon : 49.500 F ;
Classe exceptionnelle : 57.000 F.
